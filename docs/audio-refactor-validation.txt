Startup-order correction - 2026-11-02

The first cabinet run exposed a startup-order bug: ASIO starts before Spice
invokes plugin SDK entry points. The NDI source was advertised, but the graph
constructor hook never ran, leaving all audio packet counters at zero.

snapshots at startup as well as hooking subsequent graph construction. All
